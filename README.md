# 📊 Financial Portfolio Manager

An interactive, cloud-native web application built with Python to analyze market assets, track global economic updates, and simulate investment growth.



## 🛠️ Tech Stack & Features
- **Frontend & Deployment:** Streamlit Cloud
- **Data Analytics:** Pandas, NumPy
- **Financial Data:** Yahoo Finance API Integration
- **Interactive Visualizations:** Plotly (Candlestick & Linear charts)

## 📁 Project Structure
- `1. Titoli e Grafici`: Real-time stock/crypto price tracking with interactive charting.
- `2. Notizie di Mercato`: Live global economic news and institutional market feeds.
- `3. Simulatore Investimenti`: A mathematical simulation tool to evaluate compound interest growth and investment feasibility over time.
